Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn as part of the Thiranex Data Science Internship.

## Project Title
Exploratory Data Analysis on the Titanic Dataset

## Objective
The objective of this project is to analyze the Titanic dataset to uncover patterns, trends, and relationships using statistical summaries and visualizations.

## Dataset
Titanic Dataset (loaded using Seaborn)

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed
- Loaded the dataset
- Explored dataset structure
- Generated statistical summaries
- Identified missing values
- Created visualizations
- Analyzed feature relationships
- Derived key insights

## Visualizations
- Correlation Heatmap
- Survival Count
- Survival by Gender
- Passenger Class Distribution
- Age Distribution
- Fare Distribution
- Fare Boxplot
- Pair Plot

## Conclusion
This project demonstrates how Exploratory Data Analysis helps understand a dataset, discover meaningful patterns, and prepare data for machine learning.
